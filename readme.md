نظام خفيف وتلقائي لتتبع فتح وإغلاق البرامج على أجهزة الطلاب، يهدف لتوفير تقارير ملخصة يومية وأرشيف أسبوعي دون التأثير على أداء الجهاز أو إزعاج المستخدم بأي نوافذ أو إشعارات.

## ✨ الميزات الرئيسية (Features)

| الميزة | الوصف |
|---|---|
| 📋 **تتبع ذكي** | تسجيل فتح وإغلاق البرامج مع فلترة عمليات النظام تلقائياً |

## ⚡ طرق التركيب السريعة (Fast Installation)

> [!IMPORTANT]
> يرجى التأكد من تشغيل ملفات التركيب بصلاحية **مسؤول (Administrator)** لمرة واحدة فقط أثناء الإعداد.

### 🥇 الطريقة الأولى: التركيب السريع بضغطة زر واحدة (الأسرع والأسهل)
1. قم بتحميل أو فك ضغط مجلد المشروع على جهاز الهدف.
2. **(اختياري)** افتح ملف `config.json` وعدّل الإعدادات حسب حاجتك (مسار اللوج، البرامج المحظورة، إلخ).
3. اضغط كليك يمين على ملف **`Install.bat`** واختر **Run as Administrator** (تشغيل كمسؤول).
4. سيعمل سكريبت التثبيت تلقائياً ويقوم بإعداد السياسات، إنشاء المجلد المخفي، ضبط الصلاحيات، وتسجيل المهام المجدولة.
5. في النهاية سيظهر ملخص بنتائج كل خطوة. اضغط **Enter** للإغلاق.

---

### 🥈 الطريقة الثانية: عبر PowerShell (للمطورين والمسؤولين)
افتح **PowerShell** كـ Administrator واكتب الأمر التالي:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
cd "C:\path\to\Bahga-Tracker"
.\Install.ps1
```

## ⚙️ ملف الإعدادات (config.json)

يمكنك تعديل `config.json` قبل التثبيت للتحكم في سلوك النظام:

```json
{
    "logRoot": "C:\\ActivityLogs",
    "backupPath": "D:\\ActivityBackup",
    "logIntervalMinutes": 15,
    "summaryTime": "23:55",
    "archiveDaysThreshold": 7,
    "excludeProcesses": ["svchost.exe", "csrss.exe", "..."],
    "blacklistedApps": {
        "games": ["*steam*", "*minecraft*", "..."],
        "social": ["*telegram*", "*discord*", "..."],
        "vpn": ["*vpn*", "*proxy*", "..."]
    },
    "alerts": { "enabled": true, "logFile": "alerts.log" },
    "antiTamper": { "setPermissions": true, "enableWatchdog": true }
}
```

| الإعداد | الوصف | القيمة الافتراضية |
|---|---|---|
| `logRoot` | مسار مجلد اللوج | `C:\ActivityLogs` |
| `backupPath` | مسار النسخ الاحتياطي (فلاشة) | `D:\ActivityBackup` |
| `logIntervalMinutes` | فترة تكرار التسجيل (بالدقائق) | `15` |
| `summaryTime` | وقت إنشاء الملخص اليومي | `23:55` |
| `archiveDaysThreshold` | أيام قبل أرشفة الملفات القديمة | `7` |
| `excludeProcesses` | عمليات النظام المستبعدة | قائمة شاملة |
| `blacklistedApps` | البرامج المحظورة (حسب الفئة) | ألعاب، تواصل، VPN، تورنت |
| `alerts.enabled` | تفعيل نظام التنبيهات | `true` |
| `antiTamper.setPermissions` | تفعيل حماية الصلاحيات | `true` |
| `antiTamper.enableWatchdog` | تفعيل مراقب المهام | `true` |

## 📁 هيكلية ملفات النظام (Project Architecture)

| الملف | الوظيفة والدور في النظام | طريقة التشغيل |
|---|---|---|
| ⚡ **`Install.bat`** | مشغل التثبيت السريع بضغطة واحدة (يرفع الصلاحيات تلقائياً) | كليك يمين → Run as Administrator |
| ⚙️ **`Install.ps1`** | السكريبت الرئيسي لتفعيل Audit Policy وتثبيت المهام وتسجيل السجل | يتم استدعاؤه تلقائياً بواسطة `Install.bat` |
| 📋 **`config.json`** | ملف الإعدادات المركزي — التحكم في كل سلوكيات النظام | يُعدّل يدوياً قبل التثبيت |
| 🔧 **`ConfigLoader.ps1`** | تحميل الإعدادات من `config.json` مع قيم افتراضية آمنة | يُستدعى من جميع السكريبتات |
| 📄 **`install_log.txt`** | ملف سجل التثبيت والملخص المولد تلقائياً لمعرفة حالة كل خطوة | ينشأ تلقائياً عند التثبيت |
| 🕵️ **`StartupLogger.ps1`** | يسجل أحداث فتح وقفل التطبيقات مع فلترة ذكية وكشف البرامج المحظورة | يعمل في الخلفية تلقائياً (`SYSTEM`) |
| 📝 **`DailySummary.ps1`** | يولد تقرير يومي HTML + ملخص نصي مع حساب مدة الاستخدام | يعمل تلقائياً كل ليلة |
| 📦 **`WeeklyArchive.ps1`** | يضغط اللوج والملخصات والتقارير الأقدم من الحد المحدد في أرشيف مضغوط | يعمل تلقائياً كل أسبوع |
| 💾 **`BackupLogs.ps1`** | ينسخ التقارير والأرشيف والتنبيهات إلى فلاشة USB خارجية تلقائياً | يعمل كل ساعة إذا كانت الفلاشة متصلة |
| 🛡️ **`TaskWatchdog.ps1`** | مراقب تلقائي يتحقق من سلامة المهام المجدولة وملفات النظام | يعمل كل 30 دقيقة |
| 🧹 **`Uninstall.bat`** | أداة الإزالة السريعة بضغطة زر واحدة | كليك يمين → Run as Administrator |
| ❌ **`Uninstall.ps1`** | يشيل جميع المهام المجدولة ويرجع الصلاحيات للوضع الطبيعي | يتم استدعاؤه تلقائياً بواسطة `Uninstall.bat` |

## 📍 أين تجد التقارير واللوج (Log Directory)

يتم تخزين كافة التقارير في مسار مخفي وحمايته بصلاحيات النظام:
```text
C:\ActivityLogs
```

> [!TIP]
> **كيفية فتح المجلد المخفي:**
> افتح متصفح الملفات `File Explorer` ← اذهب لتبويب **View** ← فعّل خيار **Hidden items** (العناصر المخفية)، أو اكتب المسار `C:\ActivityLogs` مباشرة في شريط العنوان أعلى الشاشة.

### محتويات المجلد:
* 📄 **`process_log_YYYY-MM-DD.csv`**: سجل التفاصيل الكاملة (وقت الفتح/الإغلاق، اسم البرنامج، المسار، واسم المستخدم).
* 📑 **`summary_YYYY-MM-DD.txt`**: ملخص نصي لعدد مرات فتح كل تطبيق خلال اليوم.
* 📊 **`report_YYYY-MM-DD.html`**: تقرير HTML احترافي مع رسوم بيانية وإحصائيات مفصلة.
* 🚨 **`alerts.log`**: سجل التنبيهات (البرامج المحظورة والتلاعب المكتشف).
* 📦 **`Archive\archive_YYYY-MM-DD.zip`**: أرشيف مضغوط للملفات القديمة.

## 🚫 نظام كشف البرامج المحظورة (Blacklist System)

النظام يراقب تلقائياً ويسجل تنبيهات عند فتح أي برنامج محظور:

| الفئة | أمثلة |
|---|---|
| 🎮 **ألعاب** | Steam, Minecraft, Fortnite, Valorant, Roblox, PUBG |
| 💬 **تواصل اجتماعي** | Telegram, Discord, WhatsApp, TikTok |
| 🔒 **VPN** | أي برنامج VPN, Proxy, Tor, Psiphon |
| 📥 **تورنت** | uTorrent, BitTorrent, qBittorrent |

> يمكنك تعديل قوائم البرامج المحظورة من ملف `config.json` → `blacklistedApps`.

## 🛡️ نظام الحماية ضد التلاعب (Anti-Tamper)

* **صلاحيات NTFS**: مجلد اللوج محمي بصلاحيات خاصة (SYSTEM فقط يقدر يكتب).
* **مراقب المهام (Watchdog)**: يتحقق كل 30 دقيقة إن:
  - جميع المهام المجدولة لسه مسجلة وشغالة
  - مجلد اللوج لسه موجود
  - ملفات السكريبتات لسه سليمة
* لو اكتشف أي تلاعب، يسجل تنبيه في `alerts.log`.

---

## 💾 النسخ الاحتياطي للفلاشة (USB Auto-Backup)

* يقوم النظام بفحص وجود الفلاشة الخارجية دورياً (كل ساعة).
* المسار الافتراضي للنسخ الاحتياطي هو: `D:\ActivityBackup`.
* **لتعديل مسار الفلاشة:** عدّل الإعداد `backupPath` في ملف `config.json` قبل التثبيت.

---

## 🗑️ إزالة النظام (Uninstallation)

لو أردت إلغاء تثبيت النظام وإيقاف التتبع تماماً:
1. اضغط كليك يمين على **`Uninstall.bat`**.
2. اختر **Run as Administrator**.
3. سيتم حذف جميع المهام المجدولة (5 مهام) وإعادة صلاحيات المجلد للوضع الطبيعي.
4. اضغط **Enter** للإغلاق.

> [!NOTE]
> ملفات اللوج والتقارير في `C:\ActivityLogs` لن تُحذف تلقائياً. يمكنك حذفها يدوياً بعد الإزالة.

## 🔒 الخصوصية والأداء

* **استهلاك الأجهزة:** النظام مصمم باستخدام سكريبتات PowerShell خفيفة جداً تستهلك أقل من `0.1%` من المعالج وذاكرة الجهاز.
* **العمل في الخلفية:** يعمل بصلاحيات حساب `SYSTEM` بدون إظهار أي شاشات سوداء أو نوافذ للمستخدم أثناء عمله.
* **فلترة ذكية:** يتم تجاهل عمليات النظام تلقائياً لتقليل حجم اللوج وتحسين جودة البيانات.
